🔧 How It Works
The Travel Designer Agent project is structured into:

Agents:

DestinationAgent (suggests destinations based on mood, region, and season)

ExploreAgent (recommends attractions and local food by city)

BookingAgent (provides mock flight and hotel bookings based on inputs)

Core Orchestrator:
Coordinates agent calls based on user queries for smooth interaction.

Chainlit UI:
Provides a user-friendly chat interface that guides users step-by-step.
